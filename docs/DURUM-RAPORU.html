Faz 5'te yakalanan iki kusur: (1) öneri katmanındaki kontrol karakteri taraması no-control-regex kuralını düşürüyordu → kod noktası kontrolüne çevrildi; (2) demo istemcinin başlık üretimi tek kelimelik başlıkları 15 karaktere çıkaramadığı için öneri kalitesi %88,75'te kalıyordu → TITLE_MIN'e taşındı, ölçüm %100 oldu ve eşik 1,0'a çekildi (regresyon yakalama). Ayrıca stdio ile elle sonda yaparken stdin hemen kapanınca sunucunun yanıt yazmadan çıktığı görüldü — sonda stdin'i açık tutmalı.

Bu projede yakalanan gerçek tuzaklar (ADR'lere yazıldı)

  • TypeScript 7 bu zincirde çalışmıyor: typescript-eslint peer aralığı <6.1.0 → TS 5.9.3'e sabitlendi (ölçümle).
  • pnpm 11+ onlyBuiltDependencies'i okumuyor: install'ı ERR_PNPM_IGNORED_BUILDS ile düşürüyordu → allowBuilds haritası.
  • MCP Inspector node --import tsx … ile çalışmıyor: JSON-RPC girişini Node'a script sanıyor → sunucu artık esbuild ile tek dosya derleniyor (--bundle şart).
  • SDK sonuç tipi elle yazılamaz: CallToolResult | InputRequiredResult birleşimi bozuluyor → SDK'nın kendi tipi kullanılıyor.
  • Kural çakışması sessizce precision'ı düşürüyordu: SKU tekrarı varken kanal karşılaştırması yanlış pozitif üretiyordu → "her sorunun tek sahibi kural var" ilkesi (ADR-010) ve eval kapısı.
